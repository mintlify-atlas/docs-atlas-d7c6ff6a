Capacitor Crypto API is a cross-platform Capacitor plugin that gives your iOS, Android, and web apps a unified interface to hardware-backed cryptography. On iOS it uses the **Secure Enclave**, on Android the **StrongBox** or Trusted Execution Environment (TEE), and in the browser the **WebCrypto API** — all behind a single, consistent TypeScript API.

## Platform support

| Feature | iOS (Secure Enclave) | Android (StrongBox/TEE) | Web (WebCrypto) |
|---|---|---|---|
| Key generation | ✅ | ✅ | ✅ |
| ECDSA sign / verify | ✅ | ✅ | ✅ |
| ECDH encrypt / decrypt | ✅ | ✅ | ✅ |
| Biometric key protection | ✅ | ✅ | ❌ |
| Passkeys (WebAuthn) | ✅ | ✅ | ✅ |
| Hardware-backed storage | ✅ Always | ✅ When available | ❌ localStorage |

<Note>
  The WebCrypto API is only available in **secure contexts (HTTPS)**. Use the web implementation for local development and testing only.
</Note>

## Get started

<Steps>
  <Step title="Install the plugin">
    ```bash
    npm install @perfood/capacitor-crypto-api
    npx cap sync
    ```
  </Step>
  <Step title="Import and use">
    ```typescript
    import { CryptoApi } from '@perfood/capacitor-crypto-api';

    const { publicKey } = await CryptoApi.generateKey({
      tag: 'my-signing-key',
      algorithm: 'ecdsa',
    });
    ```
  </Step>
  <Step title="Sign and verify">
    ```typescript
    const { signature } = await CryptoApi.sign({
      tag: 'my-signing-key',
      data: 'challenge-from-server',
    });

    const { verified } = await CryptoApi.verify({
      foreignPublicKey: publicKey,
      data: 'challenge-from-server',
      signature,
    });
    ```
  </Step>
</Steps>
